1. What this is & why it exists

The TVB News 83 live stream is a normal HLS (m3u8) feed — but its URL is time-signed and expires about every hour. A media player like VLC fetches the URL once and can't run a script to mint a fresh one, so a captured link goes stale mid-session. This proxy solves that: it sits between VLC and the broadcaster, and every time the signature is about to expire it silently re-resolves a fresh signed URL and keeps serving — so you point VLC at one stable address forever, and the hourly expiry is invisible. What it does on each refresh:
  1. POSTs the broadcaster's stream endpoint for a fresh signed URL.
  2. Follows the CDN redirect to the current per-session edge.
  3. Rewrites the HLS playlists so every variant, segment and the decryption key are re-served through this same proxy (no client ever touches the CDN or the signed URL).
  4. Re-resolves before the old signature expires (every ~55 min).

2. How to read the feed (the HLS contract)

http://192.168.1.130:8060/news.m3u8          # master playlist (auto-refresh)

#EXTINF:8,                      # ~8-second segments, 25 fps
Variant rungs (chosen by the player):
  3/v1500000  → 1280×720  1.7 Mb/s
  3/v1000000  → 1024×576  1.2 Mb/s
  3/v400000   →  480×270  0.6 Mb/s
  3/a128000   →  audio    128 kbps

#EXT-X-KEY:METHOD=AES-128, URI="…/news/key"   # decryption key (public, no auth)
The decryption key is a public 16-byte file — VLC fetches it natively and decrypts transparently.

4. Requirements & limits

  • Network: player and palazzo must be on the same LAN (192.168.1.x). Outside that (cellular / remote) needs a public entry point — ask to set that up.
  • Login: none. DRM: none (only AES-128 content encryption).
  • Ads: the proxy requests the ad-marker-free variant, so no client-side ad cue-points. Broadcast commercials baked into the channel timeline remain (unavoidable on any live feed); there is no separate ad overlay.
  • Availability: runs as a systemd service (auto-starts, auto-restarts).

5. Under the hood (deployment)

  • Service: tvb-proxy.service on palazzo, port 8060, root of the box /opt/tvb-proxy/tvb_proxy.py.
  • Language: Python 3, standard library only (no dependencies) — threaded HTTP server.
  • Engine: news.tvb.com → prd-news-sc-v3-api.tvb.com stream endpoint → Edgeware HLS CDN (AES-128).
